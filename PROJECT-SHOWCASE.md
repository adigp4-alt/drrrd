# Market Research Dashboard and ForesightTape — Project Showcase

A Python/Flask project for exploring market-data views, reports, and forecast evaluation. The repository's existing application title is Iran Investment Tracker.

## What to inspect

- [Forecast routes](./app/routes/forecast.py): forecast-board, scorecard, diagnostics, historical replay, and resolution endpoints.
- [Forecast ledger](./app/forecast_ledger.py): probability scoring and calibration calculations.
- [Reporting/export routes](./app/routes/export.py): report and Excel export implementation.
- [Tests](./tests): seven test files were present in the reviewed source; their existence is not a claim that they were executed for this showcase.

This repository is designated as a GitHub template and contains application modules. Runtime availability, data freshness, forecast accuracy, and investment performance have not been verified by this review. No invented live demo or return claim is advertised.
